# 连续强调波浪与句尾收回（2026-10-13）

## 原因与修改

上一版是进入、保持峰值、退出的包络。即使延长字符之间的交错，峰值平台仍会表现为逐字开关；独立的句尾长音还会在平台保持很久。

现在改为 raised-cosine 平方的连续圆滑波峰：上升到峰值后立即回落，不含平台。相邻字符按固定相位间隔错开，间隔采用实际字时间槽并封顶 320ms，单个波峰宽度为 2.5 个间隔（最长 800ms）。相邻字符在交接处同时处于上升和回落，保持波浪流动；峰值处旁边字符只留下约 9.5% 的软尾。

采样约束保持最多两个字符明显放大，允许第三个有弱尾。逐字高亮扫色和基础上浮仍使用原有真实歌曲时间，强调波峰不改变播放进度。单个句尾长音仍有一次波峰，但不随拖长的音符持续保持放大或辉光。

原有行高、辉光遮罩、字体、翻译和背景不变；同一包络直接复用于放大、柔光和额外上浮，避免重复计算。
