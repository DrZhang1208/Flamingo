# 长音逐字歌词的亚像素上浮

## 排查

播放页已通过 `withFrameMillis` 跟随屏幕帧更新，播放器位置以 80 ms 为间隔采样后，由 `NativeLyricClock` 逐帧插值；位移由 Float 计算，绘制路径没有把逐字上浮取整。因此，提高播放器轮询频率或按“每个整像素”更新不能解决慢速字形移动的像素栅格问题。

此前每一帧直接在新的基线上调用 `drawText`。长音在最初抬升后，剩余位移小而缓慢，更容易看到字体栅格对基线的吸附。Android 文本渲染的相关限制可参考 [TextMotion / CompositingStrategy 的原始研究](https://halilibo.com/2024/why-text-gets-jittery-when-scaled-on-android.html)：TextMotion.Animated 有助于线性度和横向位置，但不能单独消除纵向基线抖动。当前真机尚未连接，未将所有掉帧原因归结为这一项。

## 改动

- 新增 `NativeLyricSurface`：每个已排版段落仅生成一次 ALPHA_8 填充遮罩，首次需要 TTML 外轮廓时再惰性生成轮廓遮罩。保留完整段落塑形、连字、双向文字和空白处的字形分区。
- 每帧通过原生 Canvas 的 `FILTER_BITMAP_FLAG` 将遮罩移动到小数像素位置；高亮渐变作为 Paint 的 Shader，透过 ALPHA_8 遮罩着色。无需每帧重新在新的基线上光栅化字形，也无需逐字创建离屏图层。
- 遮罩显式设置 `Bitmap.DENSITY_NONE`，几何已经按物理像素测量，避免系统再次缩放。
- 未修改上浮的计时曲线、音符时长、逐帧时钟或拖动进度时的直接预览。全亮、全暗和逐行模式也使用同一填充遮罩，避免在路径切换时从亚像素位置跳回字体栅格。
- TTML 外轮廓也使用相同的过滤位移；从每帧改变描边宽度改为对缓存的最大 0.9 dp 外轮廓调节透明度。填充字形保持独立，未播放部分继续无描边。
- 缓存属于测量后的段落，字体/字号/粗细、密度、宽度、文本改变后会替换；可见行虚拟化限制存活的段落数量。每个遮罩每像素只存一个 alpha 字节，未建立整首歌的位图缓存；超出 4096 px 单边或 1 Mi 像素的异常超大段落回退到矢量绘制，避免无界纹理分配。

## 验证边界

- 新增 Android 像素回归测试，以 5 秒长音的中间段验证小于 0.1 px 的实际上浮变化，以及渲染重心是否跟随连续位移。英文单词边缘裁切测试改为与独立绘制后经过过滤平移的完整段落对照，允许 1 级 alpha 舍入差。
- 本地 Skia 验证 ALPHA_8 遮罩加 Shader 的着色，以及每次 0.02 px 的过滤平移；连续上浮均无停滞，最大重心步长误差约 0.00313 px，墨迹 alpha 总量变化小于 0.01%。这验证所用绘制机制，不替代 Android 设备测试。
- 214 项 JVM 测试通过，0 失败、0 错误；Release 和 Android 测试 APK 构建通过。ADB 无设备，Android 渲染测试未执行，不声称真机刷新率、帧耗时或最终视觉已验证。
- 同时按背景反馈增强模糊、降低图层速度和权重，详见 `artwork-layered-background-20261013.md`。

## 后续幅度调整

- 逐行歌词及关闭逐字歌词的模式仅改变高亮颜色，整段文字保持原基线，不再整体上浮；自动跟随滚动和焦点放大沿用既有行为。
- 逐字普通上浮从 4 dp 降至 2 dp；TTML 长音额外上浮从 3 dp 降至 1.5 dp。保留原有布局预留空间，避免幅度调整造成行高和滚动位置变化；亚像素过滤、音符时序及长音恢复曲线不变。
- 更新长音幅度单元测试，并新增多行排版的逐行歌词像素基线回归测试，覆盖高亮前、过渡中、结束后的不同进度。
