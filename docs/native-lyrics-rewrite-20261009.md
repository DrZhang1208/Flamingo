# 原生歌词渲染重写

日期：2026-10-09

## 范围与实现

本次重写 Compose 歌词的文字绘制、播放呈现时钟及可见行运动调度；没有引入 WebView 或第三方 Web 引擎。保留歌词来源与格式解析、原始时间戳、分享和状态栏发布。

- `NativeLyricRow.kt`：在布局测量阶段一次取得文字段落与几何信息，不再等待 `onSizeChanged` 后第二次构建文字。采用原生段落塑形，保留中文、换行、字体回退及双向文字布局。暗色与亮色是一份文字表面的颜色场，不叠加底字。
- 每个源词的高亮按实际字符宽度分配到空格和折行前后。同一视觉行使用一条连续移动的颜色光带，跨字时不重新启动渐变；颜色边缘从行外进入并从行外退出。相同位移的相邻字符合并绘制。
- `NativeLyricTimeline.kt`：呈现时钟按屏幕帧推进，每 80ms 采样播放器位置；小幅滞后不让时钟倒退，显式跳转单独确认。暂停/缓冲不持续推进，恢复可见时重新建立帧时间基准。
- 上浮与高亮共用播放时间；按字符实测宽度错开源词内部字符的运动，后续字符提前 200ms 开始。主要上浮占 72%，运动时长限制在 360–650ms；末段 28% 运动与下一字符交叉，总上浮为 6dp。相邻字符及词允许同时运动。不是 Apple 官方算法，也没有宣称逐帧等同。
- `NativeLyricScrollMotion.kt`：可见行共用一个帧驱动器；改变跟随目标时保留当前位置和速度。继续使用经过回归测试的列表几何、手势和弹簧求解基础，替换原来每行独立的动画协程。
- `NativeLyricDocument.kt`：无可靠逐词时间的长介绍拆成最多 512 UTF-16 单元的懒加载段落，保留文本与原始歌词行映射，防止整篇介绍一次排版或生成逐字几何。隐藏间奏高度为零；拖动/惯性完成后 4 秒恢复跟随。
- 主页面已经接入新绘制层，移除旧 `Line` / `LyricItem` / `LyricCard` / `CountdownAnimation` UI。旧绘图辅助函数暂保留给已有像素回归作为参考，不参与主页面文字绘制。
