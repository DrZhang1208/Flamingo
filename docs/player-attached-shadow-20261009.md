# 投影附着到实际封面绘制层

此前强度调整后用户仍反馈投影不可见，不能仅从编译推断输出效果。检查了实际共享封面入口：MainActivity 中 PlayerArtworkBridgeOverlay 最后绘制，封面通过 graphicsLayer 变换；原阴影是另一个独立 Canvas。未连接设备，无法确认旧实现为何在该设备不可见。

本次删除独立投影节点，在实际封面 Canvas 内先画阴影，再通过局部 clipPath 只裁剪封面图像。共享 graphicsLayer 不再裁剪；封面和投影使用同一位置、缩放、暂停状态和页面动画时间。底部投影偏移为完整封面 16dp、紧凑封面 8dp，底部扩散分别为 19.2dp/9.6dp，叠加深色接触阴影。

背景黑色遮罩从 18% 增至 30%，原有背景亮度基础上再压暗约 14.6%；不影响封面和前景控件。

新增 Android 像素测试，检查播放/暂停两种封面尺寸下，封面下方 7dp 的像素明显比周围背景暗，确保投影绘制在封面范围之外。

验证：98 项本地单元测试通过，Release 构建及 Android 测试包编译通过；git diff --check 通过。手机未连接，无模拟器；新增像素测试仅编译，未运行，实际视觉仍待安装验证。
