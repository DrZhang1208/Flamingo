# 延长强调交叠（2026-10-13）

## 调整

在用户确认上一版交错仍显生硬后，扩大单字符包络的交叠时间：提前进入从最多 120ms / 35% 字符时间槽提高到 240ms / 65%，收尾从最多 180ms / 45% 提高到 360ms / 75%。相邻交叠约为上一版的 1.7～2 倍。

峰值从最多 240ms / 45% 调整为 320ms / 55%，收回在时间槽结束前最多 120ms / 20% 开始。这样后一个达到峰值时，前一个仍允许有很轻的回落尾部；不再要求完全清零，避免像逐个开关。

采样测试限制每个正常词内最多两个字符明显放大（包络强度 > 0.1），允许第三个有很弱的衔接尾部，避免整词或整排持续膨胀。正反向 seek 仍直接由时间计算，不引入跟随延迟。

行高、辉光强度、字体、翻译、背景及 80% 转速均不改动。
