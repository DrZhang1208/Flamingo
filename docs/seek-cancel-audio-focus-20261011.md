# 进度撤销、音频焦点恢复与间奏跳转

## 进度拖动撤销

- 取消区域由控制面板内的矩形浮层改为播放页底部升起的全宽弧形区域。曲线两端贴近底部，中央向上抬起。不透明暖白弧面整体滑入、滑出，取消状态只改变撤销图标底色和提示文字，不再使用半透明黑/红大色块。
- 命中检测使用实际弧线与绘制坐标变换，弧线上方的空白不会误触取消；只绘制提示，不截断进度条正在接收的手势。
- 进入取消区域时，显示进度在 280ms 内以端点速度为零的非线性曲线返回当前真实播放位置。目标继续跟随正在播放的进度，松手不会重启动画。
- 离开取消区时，以此时的真实播放进度重新建立拖动基准，丢弃旧预览目标、取消区内左右位移及跨越边界事件的位移。显示位置仍在 280ms 内平滑衔接；离开后新增的横向位移才调整目标，不重启动画。移出后立即松手提交重新建立的目标，显示动画继续完成。
- 真实播放时钟、暂存的拖动目标、进度条显示位置相互独立。取消期间真实进度继续前进，旧暂存进度被丢弃；在取消区松手与系统取消都不向播放器发送 seek。切歌会丢弃上一首的动画状态。
- 弧线路径按绘制尺寸缓存，回退复用现有帧循环，不增加后台高频轮询。

## 音频焦点

[Android 官方音频焦点说明](https://developer.android.com/media/optimize/audio-focus)区分暂时失去焦点和永久失去焦点。Media3 的暂时播放抑制继续交给播放器自行恢复；其他播放器长期占用焦点导致 `playWhenReady=false` 时，原实现没有返回应用后的恢复路径。

按本次用户要求，服务记录仅由 `PLAY_WHEN_READY_CHANGE_REASON_AUDIO_FOCUS_LOSS` 引起的中断。返回 Activity 时，对于同一首仍未结束的歌曲，且焦点开关开启、没有手动暂停/停止或正在淡出暂停，重新通过 ExoPlayer 请求播放和音频焦点。不会在后台循环抢回焦点，也不会把冷启动时保存的暂停状态变成自动播放。

显式暂停/停止、切歌、关闭焦点功能会取消待恢复状态；中断期间服务被系统销毁也不会持久化自动恢复标记。焦点设置现可立即更新正在运行的播放器。焦点导致的暂停不再被误报为定时关闭的“手动暂停”。

## 间奏期间点击歌词

更新播放时钟后，间奏行先在测量阶段变成零高度，再由跟随 effect 计算移动距离，可能得到零距离，目标歌词直接到达终点。

现在先利用跳转前的行高记录并启动滚动，再更新播放时钟、清除间奏占位。外部进度跳转造成的大幅时钟变化同样在更新布局前捕获移动距离。普通播放的间奏退出仍保持前一轮调整的平滑收起逻辑。

## 取消区弹簧交互细化

- 移除“移入此处”和“松开手指”两条提示，仅保留撤销图标与固定标题。弧面保持完全不透明。
- 弧面进入/退出采用临界阻尼弹簧（阻尼比 1、刚度 700），取消状态的弧面响应采用阻尼比 1、刚度 950。快速进出可以沿当前速度继续，不再每次从静止的固定时间曲线开始。
- 取消状态使弧面中央抬升高度的 6%，两端与底边保持固定；命中检测读取同一条实时曲线，避免绘制与手势区域不一致。
- 仅撤销图标使用轻微回弹（阻尼比 0.68、刚度 750），放大 12%、转动 18°、上移 2dp；图标填色连续变化，大弧面不弹跳或拉伸。
- 路径与渐变缓存复用，动画只在绘制/图层读取状态，图标颜色更新限定在小图标内部。

参考 [Compose 官方自定义动画说明](https://developer.android.com/develop/ui/compose/animation/customize)：弹簧在目标中途改变时保持速度连续，适合可打断的手势响应。本次未引入新依赖。

## 取消区高度与移出后的拖动基准

取消区高度缩小 25%：普通窗口 116dp → 87dp，小窗口 84dp → 63dp；底部内容留白同步收紧。曲线绘制与命中检测仍读取相同实际尺寸。

SeekDragSession 在取消区内仅同步真实进度，不累计水平位移；首次移出的事件只重设基准，不计入该事件的横向变化。PlaybackSeekTrack 单独读取持续运行的播放时钟，不拿正在动画中的显示进度作为真实位置。之后每次移动相对于新的手指位置累加；反复进出也遵循同一规则，松手仍只提交一次。
