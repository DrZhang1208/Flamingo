# 播放页共享元素动画（2026-10-09）

## 行为与实现

- 迷你播放条、专辑页、歌词页和播放列表共用一个可见封面图层。原位置只提供测量边界，不再各自绘制可见封面。
- 展开和收起直接使用播放面板进度，在面板局部坐标内插值位置和尺寸；手势反向会沿同一路径返回。
- 专辑页和紧凑头部切换使用可打断的边界弹簧动画。收起期间仍保留正在进行的边界动画，避免切换图层时跳变。
- 保留暂停封面的目标尺寸、切歌的已有交叉淡入，以及原有圆角形状；圆角和阴影随展开进度变化。
- 歌曲名称、歌手名称、收藏和菜单使用稳定的共享元素身份。歌词页与列表页使用同一个紧凑头部。
- 歌词整体随头部操作按钮中心的纵向动画偏移，保留紧凑状态下的相对距离。播放时间仍独立决定当前行高亮，不等待位置动画完成。
