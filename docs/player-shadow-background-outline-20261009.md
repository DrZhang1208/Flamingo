# 封面悬浮投影、背景曝光与 TTML 强调

- 封面继续使用独立 Canvas 投影，柔和层强度从 0.045 调到 0.10；下方接触层强度从 0.075 调到 0.19，偏移从 8dp 调到 13dp，模糊扩散从基准的 0.5 倍调到 0.75 倍。封面位置、暂停缩放和页面共享动画不变。
- 背景输出额外叠加 18% 黑色遮罩，静态/动态模式一致，仅影响背景，不影响封面、文字或控制按钮。
- TTML 长音保留渐变与柔光，增加 0.8dp 峰值圆连接描边和 6.5% 局部放大，260ms 渐入、380ms 渐出。短音不触发；长音结束缩放精确归一、描边归零。直接按播放时间求值，拖动进度也不会积累变形。
- 缩放作用于字词绘制与裁剪的同一个坐标变换，不重新测量排版，也不通过扩大原段落裁剪框露出相邻字。

验证：98 项本地单元测试通过（0 失败），Release 构建通过。新增长音描边/缩放结束后绘制恢复一致性的 Android 渲染测试；测试 APK 编译通过，但未执行设备测试。手机未连接，未进行真机画面、帧率或触摸验证。
