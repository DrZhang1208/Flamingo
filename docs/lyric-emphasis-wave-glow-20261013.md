# 强调波峰与辉光修正（2026-10-13）

## 问题与处理

上一版把整个单词的字符错峰限制在 260ms 内，同时每个字符继续使用完整长音时长的放大包络，容易一整排同时膨胀。现在每个字符按整词时长分配独立时间槽：在槽内 45% 处达到峰值，最多 180ms 回落。后一个字符达到峰值时，前一个已经恢复正常大小；原有高亮仍保留。英文拆音节时间轴继续按整词组织，暂停和反向拖动仍直接按时间求值。

辉光原来又受到整行扫色渐变的透明度削弱，半径也偏小。在当前字符自己的强调包络内，改为独立白色柔光，模糊半径为字号 11%，上限 4dp，使用 NORMAL 模糊遮罩并在实心文字下绘制。固定测量空间同步扩大，避免柔光被截断。遮罩仍缓存复用，并保留每段 2,097,152 像素上限，没有逐帧执行模糊。

逐行歌词、翻译、背景及 80% 转速不变。普通逐字上浮幅度不变。
