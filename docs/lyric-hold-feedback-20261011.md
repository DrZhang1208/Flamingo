# 歌词长按反馈与分享遮罩调整

- 长按底色复用 `YosRoundedCornerShape(14.dp)`；轮廓按尺寸缓存，不再使用普通圆角矩形。
- 模糊使用始终保留的 graphicsLayer。按下时只调整 RenderEffect，避免在手势期间增删模糊修饰节点。
- 按住任意普通歌词行时，全页可见歌词暂时清除模糊，自动跟随暂停。播放时钟继续运行，释放后恢复跟随与模糊。
- 按压行的文字、翻译逐渐变清晰，逐字上浮、强调上浮和描边强度随同一个按压反馈收敛。正文保持实心，松手后平滑恢复播放效果。
- 分享选词列表渐变深度由 18dp 调至 36dp，使用缓存的 quintic smootherstep 透明度采样。渐变两端斜率和曲率归零，透明端保留面板 RGB，避免黑边。列表上下内容留白同步增加到 36dp。

验证：171 项 JVM 测试通过；Debug Android 测试包编译通过。新增非高亮且带模糊行的长按保持、取消与分享手势测试，强调文字收敛像素测试，以及分享遮罩的单调、对称、端点平滑测试。当前未连接手机，Android 绘制和手势测试尚未实际执行。

## 分享选词页颜色跟随

遮罩不再自行指定白色/黑色。通用弹窗通过 `LocalDialogContainerColor` 传递实际 Surface 颜色，包含父层继承的 Material tonal elevation 及其开关；选词列表直接读取这个颜色，因此浅色模式的粉色底面也不会与渐变边缘产生色差。补充实际弹窗中开启/关闭 tonal elevation 时的遮罩边缘与空白底面像素一致性测试，Android 测试包编译通过，未执行设备测试。

未选中歌词行背景改用菜单选项相同的 `MaterialTheme.colorScheme.onSecondary`：当前浅色主题为白色，深色主题为 `#1C1C1E` 灰色。选中行继续保持白字红底。
