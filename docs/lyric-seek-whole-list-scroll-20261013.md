# 进度预览时按句内时间连续滚动整列歌词

先前直接 jumpTo 当前行，随后改为跨行时约 90ms 的短过渡。两者都只在切换行时更新目标，不能满足同一句开头、中间、结尾均连续移动的需求；本次已替换拖动期间的短过渡方案。

LyricSeekTimeline 将手指预览时间映射为当前行、下一行和句内比例。普通时间段按当前句起止时间插值：开头为 0%，中间为 50%，结束为 100%；句尾与下一句开头使用同一个滚动位置。短空白区保持已到达的下一行位置，重叠歌词在下一句开始时衔接，缺少结束时间时使用下一句开始时间。相同起始时间沿用最后一行焦点约定，并映射到分段后的文档行坐标。歌曲首尾限制在合法位置。

WavyLyricsColumnState.previewAt 每帧按真实测量行高直接计算整列 scrollOffsetPx，没有指针追赶 tween；正向、反向与停住均由同一预览时间决定。行高和翻译变化时在同一测量过程中重算插值位置。拖动时继续立即去除模糊、禁用逐行弹簧和焦点弹簧。三点间隔只在拖动期间保留完整布局高度，避免其退出收缩使时间正向而整列反向移动；点的绘制仍随预览时间变化。松手或取消后通过已有短过渡回到正常播放跟随。
