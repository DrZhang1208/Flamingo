# 连成一片的强调波浪（2026-10-13）

## 更大幅度的交错

上一版仍要求最多两个字符处于最明显的放大，导致用户认为过于分散。这次显著放宽为连续的一簇字符：

- 多字符词的相位间隔从最多 320ms 缩短到 160ms。
- 波峰半宽从 2 个间隔扩大为 3 个间隔：相邻字在中心字到达峰值时保留 56.25% 强度（原来 25%），再外侧保留 6.25% 的弱尾。
- 正常内部波峰保持总权重 2.25，最多三个字处于强放大、四个字参与明显过渡、六个字含弱尾；中心位置持续向后移动，避免一整排停在最大放大。
- 单字符时间标记保留较大的时间宽度，避免相位缩短反而让中文逐字长音的交错变少。句尾独立单字使用较短包络，起始后约 560ms 已完全收回，不会按长音时长保持辉光。

行距、字体、基础上浮、辉光强度、翻译与背景均保持原样。
