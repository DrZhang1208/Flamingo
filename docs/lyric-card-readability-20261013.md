# 分享歌词卡片背景可读性调整

最初直接放大歌词页的柔化封面，亮色及多色区域对文字有干扰。第一轮将颜色限定在 RGB 76 以下，并混合 75% 全局色，导致用户反馈过暗、与真机背景缺乏关联；该方案已替换。

当前方案重新使用歌词页 prepareFlowTexture 的柔化与饱和度处理，再将四个区域的平均色和整体平均色按 80% / 20% 混合成平滑渐变，保留更多封面区域色彩。顶部和底部保留温和的曝光变化，不再统一压到深灰色。为适应浅色封面，同时计算浅色字和深色字方案，以对原背景颜色改动最小的一种作为正文颜色；翻译不透明度提高到约 92%。仅在色彩场影响文字对比度时按需调整曝光，覆盖渐变中间色，避免纯亮或纯暗区域让文字不可读。

底部歌曲封面、字号、排版、透明边距、连续圆角及 2 倍分辨率导出保持原样；深色字卡片的底部改用轻微亮色遮罩，保持辅助文字可读。歌词页面背景不变。
