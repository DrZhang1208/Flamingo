# 换句滚动曲线调整

原生歌词的整体滚动改用五次缓入缓出曲线，默认约 520ms，按原有行参数调整在 420–680ms 之间：起步柔和，中段加速，接近目标减速，静止起步时不越过目标。行间交错延迟和虚拟列表移动视口保持不变。

新目标通过五次 Hermite 速度基函数保留被打断运动的位置和速度；正向/反向跳转、新出现的虚拟行仍共用同一动画驱动。高亮触发与换行动画开始的同步逻辑保持不变。

新增双向单调运动、前后段低速/中段高速、终点归零、打断后位置/速度连续的回归测试。

验证：102 项本地单元测试通过，Release 构建及 git diff --check 通过。手机未连接，未验证真机视觉及帧率。

## 快速收尾调整

按后续反馈改为：前 30% 时间平滑加速，30%–90% 保持速度，最后 10% 快速制动到位（默认约 52ms），取消原来较长的缓慢收尾。位置、速度连续且端点加速度归零；打断速度基函数、整体时长与行间交错保持不变。回归测试改为检查进入最后 10% 时仍保留中段至少 95% 的速度，随后精确停在目标。

## 终点保持最高速

按最新反馈去掉最后 10% 的制动段，改用三次加速曲线（进度 u³），速度在中段继续增加、到位前达到最高，到达目标时停止。被打断时用 u(1-u)² 速度基函数衔接已有速度。回归断言更新为检查整个运动过程速度绝对值单调增加、末段快于中段、位置不越界并精确停在终点。

## 恢复原曲线

按最新要求，撤销本轮自定义非线性曲线和对应测试，恢复最初的 sampleSpring 弹簧求值、原停稳阈值及原虚拟列表回归取样时间。保留逐行高亮与滚动开始同步的修复，以及此前阴影、对齐、长音强调调整。以上自定义曲线记录仅为历史，当前不再生效。
