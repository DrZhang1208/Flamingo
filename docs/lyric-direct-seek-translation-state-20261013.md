# 手动进度直跟与翻译开关状态

手动进度预览期间不使用歌词模糊、行滚动弹簧、焦点缩放弹簧或明暗弹簧。每帧直接定位预览进度对应的歌词行；即使当前行没有变化，也清除先前未结束的滚动波动。虚拟列表直接绘制零弹簧位移，不等待动画协程下一帧收敛。进度预览结束后恢复正常播放的跟随效果。
