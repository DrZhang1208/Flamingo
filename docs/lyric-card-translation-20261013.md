# 分享卡片背景、翻译字重与翻译开关

播放页翻译颜色追加修复：默认翻译底色由固定 `#919191` 改为跟随原文底色。根据后续要求取消翻译高亮，所有行的翻译始终使用未高亮时的效果，颜色不透明度固定为 35%，不再随播放焦点或按压反馈变亮；修正此前误用固定高亮亮度的实现。字体大小和字重仍沿用各自设置。Android 像素用例检查固定的未高亮亮度及焦点变化前后的一致性，需在设备上执行。

翻译和去除人声按钮的激活态复用随机播放按钮的 `overlayEffect` 加法合成方式：图标在亮底中透出页面背景，不显示实心黑色或深紫色。去除人声按钮保留展开、液面和拖动调节行为；未进入液面的图标部分仍为白色。新增彩色背景像素用例，检查翻译按钮亮底保留且图标位置透出背景，需在设备上执行。

原分享卡片从封面采样 20×20 个像素，以饱和度平方、亮度和透明度加权，取权重最大的 15° 色相区间，套用固定高饱和暗色渐变。歌词页使用整张封面的柔化色场；灰度或多色封面尤其容易产生明显色调差异。

卡片改为复用歌词页的 prepareFlowTexture：保留整张封面的色彩分布，统一饱和度处理及两次模糊，再施加相同端点的上下明暗和曝光遮罩。传入播放页实际使用的背景封面 URI，底部歌曲封面仍单独保留。缺少背景封面时使用中性灰蓝色。导出是静态色场，不截取 AGSL 动画当前的形变相位。

原 NativeLyricRow 的翻译 Text 只设置字号和字体，没有设置 fontWeight；设置页预览已经使用选中的字重。现让实际翻译复用原文样式的 fontWeight。

歌词页面增加翻译开关（后续调整到去除人声控件旁边），仅在当前歌词包含非空翻译时显示，包括其他声部的翻译。开启时使用圆角亮底图标，状态渐变和点击反馈与随机播放一致，不使用矩形波纹。开关直接同步 NowPlayingTranslation 设置，带点击震动并刷新控制栏停留时间；无翻译歌曲及其他页面不显示。

回归用例新增：灰度封面保持中性、多色封面保留两种颜色、播放页背景封面与卡片底部歌曲封面独立、实际歌词页面翻译随 Thin / Black 字重变化。需在设备上执行这些 Android 测试。
