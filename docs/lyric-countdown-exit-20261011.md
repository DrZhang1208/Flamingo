# 间奏退出与下一句衔接

## 问题与修改

原实现把三点的透明度、缩放、占用高度都绑定到同一个 320ms 退出包络；下一句在时间戳前 240ms 开始跟随，此时三点行还在收缩。行高通过 `onSizeChanged` 在放置之后回写，下一帧才修正行偏移，存在交接时的布局抖动风险。

- 将透明度、视觉缩放、占用高度分开计算。三点先缩小淡出，空隙在独立的 500ms 平滑曲线中收起。
- 三点的淡出持续 520ms，提前于下一句跟随边界 120ms 完成；缩放最低到 65%，避免缩成小点才消失。
- 占用高度在下一句的 240ms preroll 边界归零，不再于下一句跟随期间改变高度，未播放/已结束的间奏不留空行。
- `WavyLyricsColumn` 在测量完成后、放置之前批量更新行高并保持同一个可视锚点，消除迟一帧修正行偏移的问题。
- 保持同步呼吸、2800ms 周期、播放时钟驱动、暂停冻结与 seek 可直接定位。间奏生成阈值仍为严格超过 10 秒。

## 开源参考

参考 [AMLL InterludeDotsBase](https://github.com/amll-dev/applemusic-like-lyrics/blob/86200dead453bb067e554e989110cbadca8d4756/packages/core/src/lyric-player/base/interlude-dots.ts) 的独立缩放/透明度快照、退场阶段与单独位置弹簧的组织方式。该实现还使用蓄力放大后缩小的两阶段退场；本次保留应用已有的克制缩小风格，没有引入蓄力放大。

AMLL 是第三方实现，不是 Apple Music 官方代码。本次独立实现原生 Compose 时间包络与布局修正，未引入其 Web 源码或运行时依赖。
