# 统一静态与动态背景

Android 13 及以上共用同一个 AGSL 色场渲染器和同一份 96px 预柔化纹理、饱和度与曝光设置。背景效果开关现在只控制形变时钟；关闭时保留当前 phase，重开继续流动，不切回普通封面模糊图。静态模式无持续形变帧循环，切歌仍保留 900ms 颜色过渡和中断衔接。

较低版本没有 RuntimeShader，使用相同柔化纹理与近似纵向曝光作为静态降级。移除不再需要的 224px 原图/模糊图两份缓存，减少每首歌背景预处理和内存占用。

设备回归扩展了原色场测试：动态流动后关闭开关，画面保持一致并不随时间变化；保留暂停、迷你模式和快速切歌测试。当前设备未连接，设备测试仅编译，视觉结果尚未实机确认。
