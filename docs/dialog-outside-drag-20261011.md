# 弹窗列表外区域的阻尼

原来的 containDialogScroll 只有 NestedScrollConnection，能处理内部滚动控件传递的剩余位移。标题、按钮和留白等区域没有自己的滚动分发源，因此在这些区域直接拖动时不能稳定进入弹窗的弹性处理。

现在共用修饰器添加一个不消费位移的纵向 ScrollableState，使非滚动区域的直接拖动也经过同一套嵌套滚动边界。内部列表仍先消费位移；列表外上滑交给已有 DialogElasticMotion，整张弹窗按相同阻尼移动并回落。新一次下拉仍可传给 Material 进行收起，同一次手势内滚动列表到顶的隔离规则不变。未修改弹簧参数，没有新增逐帧布局。

验证：178 项 JVM 测试通过，Android 测试包编译通过。新增实际弹窗交互测试，分别把列表移到顶部、中间、底部，按住并上拖标题和按钮区域，检查位移一致、保持原高度、列表位置不变、释放回落和按钮点击；原有列表到顶的收起隔离测试一并编译。当前设备未连接，Android 手势测试尚未执行。
