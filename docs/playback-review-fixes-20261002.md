# 播放稳定性审查修复（2026-10-02）

## 改动

- WebDAV 标签读取使用限量流，不再先加载整个响应。HTTP 200 忽略 Range 时按流跳过偏移；HTTP 206 校验 Content-Range 起点，响应和流始终关闭。
- 本地切歌的歌曲、背景、歌词在同一个主线程回调中提交。已取消的刷新回调不再执行；本地、远程及音质/时长回调校验播放器当前曲目。
- 随机播放与 prepare 共用队列锁，在主线程按播放器当前曲目计算并提交队列，避免旧 UI 快照造成重复曲目或队列错配。
- 重试任务先登记再启动。可选任务统一保留取消语义；同步读取结束后检查取消状态，取消不会再触发失败重试。播放服务中的远程标签任务绑定服务生命周期。
