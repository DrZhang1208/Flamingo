# 歌词列表滚动边界

原来的最大偏移使用“总高度减去高亮锚点位置”，允许把末行的底部滚到顶部附近，导致末句离开可读区域。

现在最大偏移使用最后一个有高度的行的顶部，使普通末句最多停在自动跟随使用的锚点位置（视口高度的 6.18%）。折叠为零高度的末尾间奏不构成空白滚动目标。特别长的段落仍可滚动到内容底部，底部保留同样的安全空间；首端保持原有边界。

最后一个有高度的行索引通过 derivedStateOf 缓存，只在行数/测量高度变化时重新计算，不在逐帧滚动中扫描整个文档。手动拖动、惯性滚动、视口尺寸变化和行高变化共用同一组约束。

验证：178 项 JVM 测试通过，新增首尾重复拖动、短单行、长段落、尾部零高度行、窗口缩放与文档替换测试。Debug Android 测试包编译通过，包含实际组件到边界后的拖动/惯性滚动与可见位置断言。当前设备未连接，未执行真机测试。
