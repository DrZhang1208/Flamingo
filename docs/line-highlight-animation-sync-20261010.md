# 逐行高亮与换行动画同步

换行焦点提前 240ms 切到下一行，但逐行颜色仍使用原歌词时间戳，两者触发时间不同。本次将视觉开始时间集中到 nativeLyricVisualStartMs，滚动/焦点和逐行颜色都使用该边界。下一行开始换行动画的同一播放时刻，高亮整行并结束上一行的高亮，不等待滚动弹簧结束。

间奏倒计时没有提前量；进入三点之前的歌词维持到三点实际开始时间。逐字歌词的字词时间轴不变。缓存行的时间钳制也使用相同高亮边界，避免长间隔后旧行不熄灭。

新增同步触发、双向跳转、进入间奏的本地测试，更新整行多视觉行的像素测试时间边界。

验证：100 项本地测试通过，Release 和 Android 测试包构建通过，git diff --check 通过；手机未连接，Android 像素测试仅编译，不声称已在真机验证。
