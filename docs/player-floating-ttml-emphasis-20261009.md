# 悬浮阴影、歌词留白、封面回弹与 TTML 长音（2026-10-09）

## 实现

- 阴影改为显式绘制两层柔和投影，替换设备相关的 elevation 阴影：一层扩散环境影，一层集中在下方的接触投影。绘制时排除封面覆盖的内部区域，避免重复整块填充；阴影与可见封面共用同一边界和切页时钟。
- 歌词在原有 29dp 对称区域内预留 105% 放大空间，未放大时右侧留白增加；高亮完整放大后两侧基本相等，取整误差小于约 1 像素。右对齐背景歌词镜像处理，间奏与静态介绍不受影响。
- 恢复播放的封面弹簧阻尼改为 0.72，允许轻微负暂停进度，绕同一中心越过目标后回落。负进度限制为 -0.08，几何最大扩张小于 2.5%，正常弹簧峰值约为目标宽度的 1%；暂停仍使用临界阻尼。
- TTML 主歌词和背景歌词保留来源特效标记。用户选择长音柔和发光与强调：持续至少 900ms 的演唱字/词使用 200ms 渐入、240ms 渐退的柔光包络，配合最多 1.2dp 的额外上浮。直接按播放时间求值，拖动和暂停不依赖另一个计时器。
- TTML 特效只在逐字模式和高亮开启时启用，普通逐行歌词不添加逐字特效。绘制继续使用同一段落和字形分组，不复制一层错位正文。
