# 强调交错与行距恢复（2026-10-13）

上一版强调包络只覆盖当前字符自己的时间槽，几乎没有相邻字符交叠，导致动画像逐个开关；柔光的上下预留空间又增加了所有逐字行的测量高度。

## 调整

- 每个字符提前进入，峰值后保留当前字的长音，再于交接处快速收回。相邻字符短暂出现前一个回落、后一个上升的交错。
- 提前量不超过 120ms，收尾不超过 180ms，并按字符时间槽缩短，限制在相邻字符交叠。后一个达到峰值时，前一个已回到原大小，避免整排累积放大。
- 辉光保留上一版的独立白色柔光与缓存；不增加模糊计算频率。
- NativeLyricText 恢复原有 4dp 上浮空间与 2px 底部空间。柔光和缩放仅作为绘制效果，借用歌词行现有 10dp/14dp 外边距，不再把柔光范围加到测量行高。
- 翻译、逐行高亮及背景转速不变。
