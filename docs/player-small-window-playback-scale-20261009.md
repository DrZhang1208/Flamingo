# 播放缩放延迟与小窗口布局（2026-10-09）

## 修复

封面共享图层原本对每次测量到的播放缩放边界再启动一个弹簧，导致两个动画串联、可见封面滞后。现在仅切换专辑/紧凑头部时插值边界；同页播放/暂停缩放直接使用当前测量边界。切页中断保留当前可见位置，动画期间目标边界仍可更新。

根据播放页实际窗口约束选择布局，不依赖物理屏幕尺寸：

- 高度小于 600dp 时使用紧凑控制区，保留进度、播放、音量、歌词及队列入口，减少空白和重复底部安全区占位。
- 短横向窗口采用左右分栏。专辑页左侧封面和信息、右侧控制；歌词/队列页左侧头部和控制、右侧歌词/队列。
- 短竖向窗口仍为单栏，给控制区留出空间。
- 封面同时受可用宽高限制，避免正方形图片按全宽测量后被窗口裁切。小封面的暂停缩小幅度按封面尺寸限制。
- 歌词独立分栏时不再应用底部控制区遮罩，短竖向窗口的遮罩留白相应缩小。
- 窗口尺寸变化时按比例重映射播放面板进度，避免恢复大窗口后意外停在半展开状态。
