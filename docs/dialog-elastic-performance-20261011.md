# 弹窗弹性与资源开销检查

## 修改

- 共用 OptionDialog 的上拉边界增加连续指数阻尼，上限 24dp；整体在图层内向上平移，内容比例不变，无每帧重新测量。松手后临界阻尼弹簧回到原位，新手势可以从当前位置打断回弹。
- 保留列表手势隔离：同一次手势滚到顶部后继续拖动不能收起弹窗，松手后新的下拉手势可以收起。列表实际滚动时不触发整张弹窗拉伸。
- 合并弹窗重复的形状裁剪/阴影图层。
- 歌词高度前缀缓存只随行高度/数量变化重建，行顶查询 O(1)、可见行查询 O(log n)，代替滚动/动画时反复线性累加。保留零高度间奏行、边界包含规则、测量修正锚点和原有换句弹簧。
- 动态背景仍按约 30Hz 更新，但不再为了丢弃帧而订阅每个 120Hz 显示回调。页面退到后台时，歌词帧循环随 RESUMED 生命周期停止。
- 背景预处理移除一次重复位图拷贝，及时释放自身创建的中间模糊位图；不回收 Coil 或调用方持有的源图。
- 两处临时元数据 IO 协程改为播放服务作用域，随服务销毁取消。

## 检查范围与限制

检查了共用弹窗/滚动手势、播放器进度时钟、歌词布局与逐字绘制、封面/背景位图、后台渲染生命周期、播放服务任务生命周期，并运行全项目 Android Lint。没有以修改曲线代替性能优化，也没有改动已确定的歌词滚动弹簧。

新增单元回归覆盖阻尼连续性/上限、反向拖动、手势重入、列表隔离，以及 300 行随机高度（含零高度）的缓存/二分结果与原线性布局逐项对照。新增设备测试覆盖回弹中途接管与最终归位。

当前无连接设备，设备测试只编译；本地单测、Lint 和构建不代表实机 120Hz 达标。仍需在目标手机上抓取播放中开关歌词、弹窗拖动、长歌词浏览的帧时间，确认 CPU/GPU 掉帧来源及改进幅度。

## 全量 Lint 结果

首次全量检查报告 137 个 error、123 个 warning 和 4 个 hint。其中 119 个 error 属于 Media3 UnstableApi 的显式 opt-in 声明，12 个是缺少翻译，3 个低版本 API 调用，1 个广播注册 flag，1 个 remember 返回 Unit，1 个 AnimatedContent 未使用 target 参数。

本次修正了新缓存校验的 remember 返回值，以及背景软件位图转换缺少 API 26 判断的问题。其余告警保留在 `app/build/reports/lint-results-debug.html`，未通过关掉 Lint 或新建 baseline 隐藏。该扫描发现的是静态问题，不等同于掉帧原因；全量 Lint 仍未通过。

最终验证：120 项单测通过，0 失败；Release 与 Android 测试 APK 构建通过；全量 Lint 复跑仍报告 135 个 error、123 个 warning、4 个 hint。未连接手机，未运行设备测试或帧时间采集。已在 Finder 中显示本次 Release。

手感调整：根据反馈取消上拉缩放/拉伸，仅保留整体 translationY 平移、渐进阻尼和可打断回弹。

顶部裁剪修复：把阻尼平移从内部卡片移到 ModalBottomSheet 的 modifier，平移发生在 Material Surface 裁剪之外，避免仍按旧边界截掉上移后的顶部圆角。
