# 阴影过重及长音描边绘制修复

用户截图确认封面投影现已出现，但形成过重黑边；歌词出现空心轮廓和跨行重复。

- 投影此前将强度应用于每一个叠加壳层，导致多次 alpha 合成后远比目标浓。现按二次衰减权重归一化每层透明度，保证每个光晕层的最终透明度不超过其目标值。两层目标分别为 10% / 32%，即完全重合也不会超过 38.8% 黑色。底部偏移由 blur 改为 0.6 × blur，完整封面从 16dp 减至 9.6dp；扩散从 1.2 × blur 减至 1.1 × blur。保留同节点绘制与只裁剪图像的结构。
- TTML 描边后明确传入 Fill、alpha=1 和无光晕时的 Shadow.None，避免共享段落绘制状态残留为 Stroke 或旧阴影。普通高亮仍为实心文字，描边仅为长音附加效果。
- 段落按视觉行裁剪时移除为光晕额外扩张的上下区域，防止整个段落中的相邻视觉行被再次绘制。
- 新增多行长音的实心像素覆盖率及特效结束后绘制恢复测试；阴影像素测试同时验证可见性和不过黑的上限。
