# 歌词首端视觉边界与分享页返回恢复

## 本次问题

首端逻辑偏移已有边界，但 WavyLyricsRow 在布局后仍叠加逐行弹簧位移。自动跟随或跨句跳转尚未结束时，向下拖到逻辑首端，旧位移仍可将首行推到视口下方。此前只覆盖静止列表的边界测试，未覆盖这一组合场景。

歌词分享页覆盖期间停止了播放时钟。返回时，少于 500ms 的真实时间差沿用了播放中防抖校正，每 80ms 最多补 12ms，导致几秒钟内追赶进度。滚动弹簧则仍在覆盖期间驱动帧；原长按状态也没有显式跟随页面的可交互状态关闭。

## 修改

- 用布局偏移减去弹簧位移得到实际滚动坐标，再限制到统一首尾边界；绘制和虚拟化采用相同边界。范围内仍保持原本交错弹簧，不改变正常逐行跟随参数。
- 分享页覆盖或歌词页隐藏后，停止滚动弹簧帧循环并结清旧位移，保留文字排版缓存；返回后只动画新的跟随目标。
- 播放时钟恢复后的第一份位置报告立即同步，之后仍保留正常播放防抖与显式 seek 等待逻辑。
- 覆盖歌词页时禁用底层歌词手势并清除长按反馈；后台不再发起跟随跳转。

## 验证边界

- JVM：183 项通过，新增首端未完成大幅前跳后连续下拉、末端反向位移、隐藏/恢复滚动驱动、短/长时间差首帧同步、显式 seek 不被覆盖等回归。
- Android 测试增加未结束跟随动画中的实际反复下拉，以及长按打开分享后重新启用交互的用例。仅编译，未连接设备执行，无法据此确认真机帧率或宣称真机问题已复测消失。
