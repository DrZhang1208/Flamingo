# 歌词渲染重写计划与验收

日期：2026-09-09

## 本轮目标

先解决两个明确反馈：切歌后的多余整页缩放、每次换行闪烁。保留逐字高亮、上浮、翻译、伴唱、模糊设置、波浪滚动、点击跳转及长按分享。解析格式与歌词来源优先级保持现有行为。

## 已确认的代码原因

- `ApkYosLyricView.kt` 随歌曲键变化执行整页 `1 → 1.1 → 1` 缩放。
- 自动跟随先跳 `currentLineIndex + 1`，下一帧再跳回当前行，连续中断滚动动画。
- 同一页面还通过 48ms/80ms 定时跳转修正布局，多个效果共同写入滚动位置。
- `YosLyricView.kt` 的当前、已播放、待播放分支采用不同高亮/上浮绘制路径，行状态改变时出现离散变化。
- 文字尺寸用行高估算、字符裁剪及透明度合成方式存在额外的边缘/亮度风险。

这些是源码可确认的机制；实际设备上的每一种闪烁仍需录像验证，不能把源码分析当作全部视觉问题的根因证明。

## 实施顺序

1. 去掉切歌时额外的整页缩放及重入动画；自动跟随只提交一个真实目标。
2. 排版测量与行身份稳定化：字体变化更新布局，不重建整行动画；测量修正由滚动容器处理，移除固定毫秒补偿。
3. 统一逐字绘制路径：行状态只影响连续强调，不切换文本几何和完成时刻；保持词时间及上浮连续。
4. 修整滚动动画的中断和行高更新，新增对应回归测试。
5. 运行全部单元测试与 Debug APK 构建，检查本轮差异。
6. 真机逐项验证下表；无设备时明确标为待验证。

- 预览：将“正在拖动”和“预览保持”分开；拖动/惯性期间不自动跟随，停止后等待 4 秒；再次操作重新计时，明确点击歌词跳转则恢复跟随。预览中实测行高变化保持当前可见行。
- 间奏：三点标记固定布局，提前以弱强调显示，开始/结束只连续调整透明度，移除空行展开后的延迟入场。
- 上浮：运动时长限定 220–650ms，长音完成上浮后保持；相邻单位允许提前启动与交叉，实际歌词时间戳不变。

## 暂停封面共享转场补充

- 用户补充暂停时歌词页返回封面页会先放大到播放尺寸再缩回。共享元素原先使用未缩放的布局边界，而暂停缩放仅在图层上，造成转场终点不一致。
- 页切换时记录当前播放动画进度，用该进度建立共享元素的真实布局尺寸；播放动画只绘制相对这次布局基准的剩余变换，并放在共享元素内容内部。播放/暂停每帧仍不改变布局，页切换目标尺寸则包含当前暂停状态。
- 新增共享转场逐帧像素测试：暂停状态进入封面页时，红色测试封面宽度不得超过最终暂停宽度后再缩回。
