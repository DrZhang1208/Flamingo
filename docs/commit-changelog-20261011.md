# 2026-10-11 提交变更日志

本日志记录自 `e3b0a2cd`（原生歌词重写基线）以来的累计改动。各专题文档保留迭代过程，本文件描述本次提交的最终行为及验证边界。

## 歌词渲染、时序与交互

- 移除模拟时间轴的“智能逐字歌词”功能，增加真实逐字歌词开关；开启时仅对带逐字时间戳的歌词使用逐字效果，其余使用逐行效果，关闭时统一逐行显示。
- 逐行高亮直接根据播放时间开始，不再依赖滚动是否到达最终位置。跳转进度时同步重置行强调状态，避免跨过的歌词连片闪亮或变暗。
- 连续高亮按排版后的可视行处理渐变，覆盖长句换行、英文单词、空格及字形边界；保留相邻字上浮的交错，减小普通上浮幅度与行间距。
- 当前行保留放大效果，以起始边固定的变换和尾部预留宽度保持对齐，避免动态缩放造成右侧留白过小或重新换行。
- TTML 长音强调采用独立的描边、轻微放大和额外上浮；保留正文填充，限制光晕强度，避免描边影响未高亮区域。字形按阅读顺序交错上浮和回落，而非整词同时回落。
- 间奏三点只在相应时间段占据布局，以缩放和透明度进出；三个点同步进行较慢呼吸，暂停时冻结在播放时钟位置。
- 手动浏览歌词期间关闭模糊；只有前台歌词页接受滚动、点击跳转和长按，阻止播放列表空白区域穿透到后台歌词。
- 首次暂停进入歌词页时，遮罩使用布局坐标而非动画后的全局坐标，避免歌词直到播放后才出现；过渡期间歌词底部保持渐隐且不越过控制区域。

## 播放页与封面连续动画

- 迷你播放条、专辑页、歌词页和列表页共用封面加载状态与共享绘制桥，减少重复解码、重复图层交接和闪烁。
- 切歌使用可中断的封面交叉淡入；旧图保持底层不透明，避免过渡中间出现暗帧。快速切歌从当前可视状态继续。
- 歌名、歌手、收藏及菜单按钮使用共享位移/缩放；文字按端点宽度排版再缩放，减少动画中省略号、遮挡和跳变。
- 播放/暂停封面缩放围绕中心进行，处理暂停状态切页、切歌后立即暂停及动画被打断；播放启动保留小幅弹性强调。
- 调整打开播放页和切页动画速度；手动拖动结算保留速度和打断能力。歌词页与列表页切换使用缩放和透明度过渡。
- 根据实际窗口约束适配低高度、横向小窗口及分屏；窗口尺寸变化保留展开比例，封面居中，控制按钮保持可达。
- 封面阴影与可见封面置于同一绘制表面，缓存软件模糊纹理，控制浓度与扩散，避免多层阴影累计或在错误裁剪层失效。
- 进度条使用完整圆端点，从零进度也显示高亮圆点；音量条复用同一绘制逻辑。播放进度由帧时钟插值，低频更新文本与播放器采样。
- 歌词及列表切换按钮增加触觉反馈。剔除人声控件增大并使用平滑圆角，按填充区域区分图标前景以改善对比度。

## 播放状态与资源开销

- 网络中断且仍有播放意图时显示等待状态，并按递增延迟重试可恢复的连接错误；主动暂停、切歌、播放结束和服务销毁取消旧重试。
- 迷你播放条与完整播放页统一显示缓冲状态，缓冲时点击按钮执行暂停意图。
- 歌词布局缓存行高度前缀，以常数时间查询行顶、二分查找可见范围，减少每帧线性累加。
- 对已结束或尚未开始的静态段落合并绘制；活跃文字保留逐字渐变和强调效果。
- 合并歌词重复的全视口离屏遮罩，缓存遮罩几何、画笔和渐变；减少每帧布局和缓存重建。
- 背景预处理减少位图复制并释放自身中间图，不回收 Coil 拥有的源图。元数据 IO 任务改由播放服务作用域管理。
- 页面退到后台时停止歌词帧循环，背景形变采用约 30Hz 更新，避免订阅高刷新回调后再丢弃多数帧。
- Android 13 及以上静态/动态背景共用 AGSL 色场与预柔化纹理；关闭动态仅冻结形变相位，保留颜色与曝光效果。低版本保持静态降级，切歌保留色彩过渡。

## 歌词选取、分享图和共用弹窗

- 歌词选取复用 OptionDialog，封面与已选数量作为页头；选中歌词为强调色红底白字，保留最多 14 行的限制和顺序。
- 保留原来的横排保存/分享按钮，减小底部留白；选取列表上下增加渐隐和内容内边距。
- 分享图为带透明外边距的 PNG，卡片与内部封面使用平滑圆角；歌词置于正文，底栏显示歌名、歌手、应用图标和封面。
- 使用 1080px 逻辑排版直接以 2 倍尺寸绘制，输出宽度 2160px；长选取自动扩展高度，超出上限时明确失败，避免静默截断。
- 封面使用 Coil 软件解码和中心裁切，保存/分享结束后释放导出位图；应用标识使用真实软件图标。
- 弹窗上拉改为整张卡片的阻尼平移，取消拉伸；松手后平滑回弹，新的手势可打断。平移置于 Surface 裁剪外侧，避免顶部圆角被截断。
- 列表同一次手势滚到顶部后继续拖动不会收起弹窗；松手后新手势可以在边界接管弹窗拖动。
- 歌词设置预览改为白底黑字、灰色翻译，取消预览上下遮罩及多余嵌套视口。

## 曲库统计与排序

- 歌手显示“x 首歌曲·x 张专辑”；合作歌手每首歌曲只计一次，专辑按既有分组规则去重。
- 歌手支持名称、歌曲数、专辑数排序；专辑支持名称、年份、更新时间、歌手、曲目数排序。名称按拼音及大小写不敏感规则比较，同值保持稳定次序，未知日期始终置后。
- 各方式与方向按曲库快照在后台预计算；切换直接选取缓存结果，不重新启动排序，也不运行大量项目重排动画。
- 页面持有 Lazy 列表状态，排序变化时请求回到顶部；搜索结果沿用当前排序。
- 移除可变排序设置 getter 上错误的 @Stable 声明，使 Compose 正确处理模式和方向变化；增加真实设置 getter 的重组回归。
- 歌曲、歌手和专辑复用排序菜单，移除独立降序按钮。再次点击已激活的选项反转方向，显示箭头及无障碍说明，保留已有偏好。

## Release 发布与可复用上传脚本

- `assembleRelease` 打包后调用 WebDAV 上传任务，通过 AGP output-metadata.json 获取实际 APK；没有本机配置时跳过，上传失败保留本地构建并发出警告。
- 脚本支持指定文件、远端名称、目录和私有配置；凭据不入库、不打印，也不携带 Authorization 跟随重定向。
- 支持 SabreDAV 1 MiB 分块 PUT/PATCH、临时错误重试、下载校验前缀后续传；完整 SHA-256 和大小通过后 MOVE 发布同名正式文件。
- 提供访问/读写/清理临时探针检查；临时文件按目标名称与内容散列区分，不清理无关服务器文件。
- 本机已安装 `$webdav-upload` Skill；本仓库保存独立脚本与使用文档。Skill 本身位于用户的 Codex skills 目录，不是应用运行时依赖。
