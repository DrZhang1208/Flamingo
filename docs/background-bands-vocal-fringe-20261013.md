# 背景长条色带与去除人声按钮矩形边框

背景部分后来按用户要求撤回，当前已 [恢复到掉帧反馈前的动画](background-animation-restore-20261013.md)。按钮矩形残边的修复继续保留，下文为阶段记录。

## 背景

用用户截图中《无问》的封面裁图复现了问题。上一轮将全屏模糊移到纹理预处理后，原半径 20 的预模糊仍保留封面文字、人物等明暗纹理，UV 扭曲与小图层叠加会将这些纹理挤成细长条纹。另外，图层羽化半径 0.65 超过纹理半宽 0.5，可能暴露 CLAMP 重复的边缘颜色。

- 256×256 F16 纹理的三次滑动窗口盒式模糊半径增加到 56，仍只在封面更新时于后台处理，不增加每帧模糊。
- 叠加图层的羽化在半径 0.5 归零，阻止纹理外的边缘重复参与融合。
- 最小色彩图层的尺寸由长边的 25% 调整为 40%，让色彩区域更宽，避免叠加出窄条纹。
- 保持原曝光、饱和度、四层融合、72% 转速、网格复用及停止播放时冻结。分享卡片与旧系统的 `prepareFlowTexture` 路径不受影响。

## 按钮

截图放大后可见，平滑圆角之外仍有白色矩形细线。反向裁切遮罩外矩形与白色填充矩形重合，在半像素位置或按压缩放中，两条抗锯齿边缘不能完全抵消，留下残余颜色。

将反向遮罩的外矩形向四边扩展 4 dp，确保填充矩形外缘被完整清除；内侧连续圆角路径保持不变。仍在独立的加法合成层内绘制，保留底边固定、展开收起和图标透出背景的行为。

## 验证

- 本次 JVM 220 项测试通过，0 失败/错误/跳过；Release 与 Android 测试 APK 构建成功，`git diff --check` 通过。
- 新增 JVM 回归：窄条文字纹理融合后 16 像素内的通道差低于 0.02，同时红蓝大色区的通道差仍超过 0.65，避免靠压暗或均色消除条纹。
- Android 按钮像素回归新增半像素平移及四个外角像素探测，覆盖按压、展开和收起阶段。仅编译检查，未在设备执行。
- 软件 Skia 编译当前实际背景/收尾着色器，使用相同 UV 网格和截图封面生成 240×532 的对照。在相位 0/24 秒，收尾前 F16 图像的局部纹理 RMS 从 2.343/2.789 降为 0.447/0.473（换算至 8-bit 通道尺度）；这只是该封面、该局部纹理指标，不代表帧率或所有封面的观感。
- 覆盖探针确认纹理外的叠加权重为零；彩色渐变夹具仍保持区域颜色和连续运动。该灰色封面对照最终平均 RGB 由 95.83/93.38 变为 93.76/91.03，曝光参数未改变。
- 采用圆角矩形模拟相同的反向遮罩操作，在多个半像素位置及 1/1.17/1.35 倍缩放中，角外白色残留最大从 64 个色阶降为 0。该检查验证遮罩抗锯齿原因，不能替代 Android 上的实际连续圆角绘制回归。
