# 进度撤销弧面与进入 / 退出反馈

参考用户提供的输入法语音 UI，调整底部取消区的曲线与手势反馈，保留现有不透明暖白弧面、固定撤销标题和区域高度。

- 顶边改用一段连续椭圆弧，扩大横向半径，中央形成圆润的宽弧冠。绘制路径与命中检测使用相同的椭圆参数。
- 进入取消区时，中央抬升由区域高度的 6% 增至 26%：普通窗口约 5.2dp → 22.6dp，小窗口约 3.8dp → 16.4dp。两端和底边固定，底部不会出现空隙。
- 撤销图标放大由 12% 增至 26%，转动由 18° 增至 26°，自身上移由 2dp 增至 5dp。图标和标题所在行额外整体上移 8.5dp、放大 3.5%。
- 弧面响应弹簧刚度由 950 降至 420，出入场由 700 降至 500，使较大的形变有更完整的展开与收回过程。弧面仍为临界阻尼；图标保留轻微回弹，快速反向时沿当前状态继续。
- 普通 / 小窗口的区域高度仍为 87dp / 63dp。进度撤销、移出后的拖动基准和松手提交规则沿用现有实现。

验证：190 项 JVM 测试通过，包含调整后的中央抬升、两端固定、对称性和区域底部约束；Release 与 Android 测试 APK 构建成功。设备回归增强为检查高于原始区域 18dp 的实际绘制和命中，未执行真机视觉验证。
