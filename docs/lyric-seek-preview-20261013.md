# 歌词实时进度预览与翻译按钮位置

翻译开关从底部导航栏移到去除人声控件旁边，复用该控件所在的右侧浮层位置。仍仅在歌词页且歌曲带翻译时显示。取消默认矩形点击波纹，使用与随机播放相同的无波纹点击、10dp 连续圆角、开启底色与图标颜色渐变，保留点击震动。

拖动进度条的显示位置通过独立 LyricSeekPreviewState 传给歌词渲染器，每帧直接用于高亮与跟随行定位，不经过播放器采样间隔、进度去抖或返回界面的高亮平滑。预览开始时退出歌词手动浏览状态；预览期间不使用服务发布的实际播放行作为额外高亮行。

进度条与歌词使用同一个预览值，包括进入取消区域时回到实时播放位置的过渡。预览不会更新播放器或发布给外部的歌词位置。松手提交后保留带版本号的跳转命令，让歌词时钟抵抗播放器延迟上报的旧进度；取消时不产生跳转命令，过渡完成后继续跟随后台实时播放时钟。预览状态随歌曲重建，控制栏移除时清除预览。

新增两项 Android 页面像素回归：正向和反向拖动改变逐字高亮、取消后返回实际进度且不触发 seek；松手后播放器仍上报旧位置时保持提交位置的高亮。需在设备上执行。
