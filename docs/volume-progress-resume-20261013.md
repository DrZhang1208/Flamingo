# 音量拖动跟手和播放进度恢复动画

音量滑块原本在拖动写入系统音量后，会被系统广播改回整数音量档位，造成拖动过程吸附。VolumeSliderState 现在分别保存手指的连续位置和系统实际音量，拖动距离按控件真实宽度换算；系统广播只更新实际档位，不覆盖手指位置。松手或手势取消后重新读取系统音量，用 280ms 平滑过渡对齐实际档位。继续拖动可以从当前可见位置中断对齐动画，硬件音量键的更新也保留平滑过渡。

PlayerProgressState 提升到播放页控制区 AnimatedVisibility 外，并通过 rememberSaveable 保存显示位置与时长。隐藏控制区、收起播放页、应用进入后台后，重新显示时从最后显示的位置平滑过渡到最新进度；同一歌曲的外部进度跳变也进行过渡。真实播放时钟立即同步，拖动与取消仍使用真实进度。自动恢复动画不发布歌词拖动预览，手动拖动继续直接跟手，取消后继续使用原有返回动画。切换歌曲时重建对应状态。
